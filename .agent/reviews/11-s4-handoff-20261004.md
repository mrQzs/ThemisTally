# 11 S4 交接与预算复审（2026-10-04）

## 结论

离线 S4 通过 `LOCAL_REFERENCE`；真实 09 启动、provider、Pi、进程 runner 和外部连接器保持 `NOT_RUN/BLOCKED`。

## 实现

- `PlanningHandoff` 绑定 request/run/operation、planner profile/session、context 与 PlanningBundle 的不可变 ResourceRef 和精确字节摘要。
- `bind_planning_result` 要求 request、context manifest、资源允许集和 bundle 互相闭合；不创建 approval、publication 或执行身份。
- `ingest_planning_handoff` 只把已细化的 `ContractIR` 交给 09 `PlanningService` 生成 DRAFT，审核和发布仍由 09 负责。
- `ExecutorHandoff` 绑定 candidate/report/invocation/result/event/check 证据，并拒绝 settled/status、摘要或引用闭包不一致。
- `PlanningBudgetLedger.require_operation` 只读检查 reservation 的 request/task/generation 和活动状态。
