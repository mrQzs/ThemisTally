## 约定

- 安全读取是纯函数、不缓存：`logs cat` 是一次性的进程，缓存只放在服务层（`(路径, 大小, 修改时间纳秒, 文件号)` 与游标标识）。
- 改变现有行为之前，先找钉住旧行为的测试（尤其 `tests/test_kit_logs_oracle.py`，第一轮的 oracle）；要改 oracle 时在提交说明与闸二提示里明说。
- `logs search` 改造前后各在真实的 `.agent/runs` 上计一次时，变慢明显就如实报告。
- D1 后台三片做完、最后一轮闸二之前，按记忆里的办法逐个文件跑一次全量。
- 本会话的环境里设置了决策模型的 `TYPESAFE_API_KEY`：`test_decisions.py` 与 `test_kit_config.py` 各有一条假设它没设（与本片无关）。跑测试用 `env -u TYPESAFE_API_KEY`。
- 变异检查的脚本给每个变异设时限，超时单列，不算“抓住”：脱敏卡住时，被结束的进程退出码也不是 0（第 1 轮整改时实际发生过一次）。
