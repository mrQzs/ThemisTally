调度每一次转交都经协调人 womovie-c8；已激活 JEV 时，在一审、终审之前各调用一次。
基准测试一审通过后与合同一起锁死；战后只能追加白盒测试，不能改基准。
门禁不过带报错日志直接打回执行端，不调 JEV，不进审核端。
打回给谁一审按责任退回合同端或门禁端；终审退回执行端，合同有缺陷时退回合同端。
打回上限同一处连续打回超过 3 次，上报规划端重拆；重拆后仍卡住，才上报站主（你）。
上报站主两种：规划端重拆后仍卡住；协调人遇到超出它权限的「需协调人决定」（放宽路径范围、改合同目标）时转交。只有这两种进金色的「上报给你」。
一个回合收到信才被唤醒（续接会话）：收信 → 干活并更新 state.md → 写 report.md → 交信给协调人 → 退出，不常驻等待。
工具禁令禁止 advisor、子代理派遣与外部插件；内核每回合审计会话记录，越权调用会让这一回合的交付作废。
